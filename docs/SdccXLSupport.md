# XL3/XL4 Format Support (ASlink/SDCC) in lk80

## What was done

New XL3/XL4 parser in `lk80.c` — automatically detects the file format (binary MS-REL or text XL3/XL4) by the `XL` signature in the first two letters.

## Added Structures

- `SdccGlobalArea` — global area by name (REL/ABS, CON/OVR, size, base)
- `SdccAreaInst` — area instance per module (offset within the global area, resolved absolute base)
- `is_sdcc` field in `Module`, `sdcc_area_local` in `Symbol`
- External symbols table per module (`mod_ext_syms`) for resolution in R lines

## Added Functions

- `is_xlf_file()` — format detection
- `xlf_pass1()` — scans H/M/S/A lines, builds areas and symbols (skips T/R)
- `xlf_pass2()` — processes T/R lines, applies relocations, writes to output_buffer
- Integrated SDCC layout after the existing MS-REL layout

## Supported Relocation Cases

- **Word** (2 bytes): reference to an area or external symbol
- **Byte** (3-byte or 4-byte group in T-line depending on XL3/XL4): LOW or HIGH of a relocatable address
- **ABS+OVR**: absolute areas where the T line offset is the absolute address

## Tests created (`tests/`)

| Test | What it validates |
|---|---|
| `xlf_simple` | Simple bytes without relocation |
| `xlf_area_reloc` | Word relocation referencing its own area |
| `xlf_ext_cross` | Cross-file external symbol |
| `xlf_abs_area` | ABS+OVR area with absolute address |
| `xlf_byte_reloc` | LOW and HIGH operators (1-byte relocation) |

## Technical Context

The XL3/XL4 format is the relocatable file format generated by SDCC (via SDAS) and by Nestor80 in `--build-type sdcc` mode. Added command line options `--build-type sdcc-xl3` and `--build-type sdcc-xl4`, keeping `--build-type sdcc` defaulting to the latest standard (XL4). It is a text format, unlike the binary MS-REL format (LINK-80/MACRO-80) that lk80 already supported.

Structure of an XL3 or XL4 file:

```
XL3 or XL4
H <num_areas> areas <num_symbols> global symbols
[M <module_name>]
S .__.ABS. Def000000
[S <ext_sym> Ref000000]   ; external symbols (before areas)
A <area_name> size <SS> flags <FF> addr <AA>
[S <pub_sym> Def<NNNNNN>]  ; public symbols of this area
T <lo> <hi> 00 <bytes...>  ; assembled data (Note: 4 bytes for XL4 address)
R 00 00 <ai_lo> <ai_hi> [<flags> <offset> <idx_lo> <idx_hi>]...  ; relocations
```

Area flags (`FF`): bit2 = OVR, bit3 = ABS.

Relocation flags: bit0 = byte (3-byte group), bit1 = symbol reference (vs area), bit3 = 2-byte format, bit7 = use high byte (MSB).
